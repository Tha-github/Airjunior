## DIREÇÃO DE DESIGN

O site deve transmitir a sensação de um escritório de advocacia consolidado.

Evitar aparência de template genérico.

Utilizar:

- bastante espaço negativo

- títulos grandes
- divisórias discretas
- cards sofisticados
- ícones minimalistas
- animações suaves
- microinterações
- transições elegantes

Não exagerar em:

- sombras
- gradientes
- animações
- bordas arredondadas

## REGRAS DA OAB

## REGRA CRÍTICA

Não invente informações sobre o escritório.

Quando uma informação não estiver disponível, utilize placeholder claramente identificado ou prepare o componente para receber posteriormente o conteúdo.

Não altere funcionalidades implementadas nas etapas anteriores sem necessidade.

Cada nova etapa deve continuar o projeto existente.

Antes de programar uma etapa:

1. analise os arquivos existentes;
2. identifique os componentes já implementados;
3. preserve o padrão visual;
4. reutilize componentes;
5. evite duplicação;
6. implemente apenas o necessário para a etapa atual.
